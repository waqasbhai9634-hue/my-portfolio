# My Developer Portfolio

## Overview
My Developer Portfolio is a personal website that introduces me and showcases my software development journey.

## Problem
Beginners need a simple way to document their work and present completed projects in one place.

## Solution
I created a responsive website with an introduction, an about section, a skills list, project cards and contact links.

## Technologies Used
- HTML
- CSS
- JavaScript

## Features
- Responsive layout
- Navigation between sections
- Dynamically generated project cards
- Project status labels

## What I Learned
I learned how to structure a webpage, style layouts with CSS, manipulate the DOM with JavaScript and test a website in a browser.

## How to Run
1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
